NCPD PATROL - OPTIONAL CHINESE LOCALIZATION PREVIEW v0.1a
简体中文 / 繁體中文 — 部分文本翻译预览 / 部分文字翻譯預覽

Requires the main NCPD Patrol mod and its normal dependencies. Tested against
NCPD Patrol 0.17d and the earlier career build's localization keys. This is an
add-on, not a standalone mod or a full translation. It replaces only the text
provider r6/scripts/NCPDPatrol/NCPDPatrolLocalization.reds and adds journal text
resources. Install after the main mod and let this file win any mod-manager
conflict. Reinstall this language pack after updating the main mod.

INSTALL
Install NCPD Patrol first. Extract this whole ZIP into the Cyberpunk 2077 folder
that contains r6 and archive, then restart the game. Select Simplified Chinese
(zh-cn) or Traditional Chinese (zh-tw) as the game's interface/text language.
Both languages are included and selected automatically. English/other languages
retain the main mod's English fallback. Existing Codeware, ArchiveXL, redscript
and other main-mod dependencies are sufficient. Browser Extension is not needed.

TRANSLATED (49 keys per language)
- Start/end shift, patrol menu and backup interaction/button captions.
- Available/Busy, repair, new partner, cancel/new dispatch, stats and 10-4 buttons.
- Partner revive and suspect arrest interaction captions.
- Bean Bagger weapon name/description.
- All six scanner dispatch journal briefings, plus VIP and cyberpsycho journals.

STILL ENGLISH
HUD, notifications, career pages, CET controls/logs, popup headings/help and any
other hardcoded text are not translated in this preview. This package supplies
text only. It changes no quests, rewards, NPCs, spawning or gameplay scripts.

VALIDATION AND FEEDBACK
Translation-key coverage, compiled localization round-trip/extraction, provider
source/API compilation and ZIP contents were checked offline. Actual game font
rendering and Chinese terminology still need a Chinese player's review. This is
a draft translation, not a claim of official terminology/native proofreading.
Please check missing/square characters, clipped labels and journal wording.

UNINSTALL
Delete these two add-on resource files:
archive/pc/mod/NCPDPatrol_Chinese.archive
archive/pc/mod/NCPDPatrol_Chinese.archive.xl
Reinstall the main NCPD Patrol package to restore its original
r6/scripts/NCPDPatrol/NCPDPatrolLocalization.reds, then restart. Keep the other
main NCPD Patrol files. Do not leave two copies of the provider script installed.
